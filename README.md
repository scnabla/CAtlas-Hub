# CAtlas Hub

[项目主页](https://github.com/scnabla/CAtlas-Hub) · [版本下载](https://github.com/scnabla/CAtlas-Hub/releases) · [问题反馈](https://github.com/scnabla/CAtlas-Hub/issues)

CAtlas Hub 是一款支持 Windows 和 Linux 的 VS Code 扩展，将项目集合、代码浏览和个人待办集中到侧栏，方便在多个工程和文件之间切换。

- **项目集合**：为分散的文件夹和工作区设置别名，集中选择与打开。
- **已打开文件目录**：按目录查找正在阅读的文件，整理工作区外的标签。
- **增强函数大纲**：浏览函数、类型和 C/C++ 条件编译分支，搜索并跳转到源码。
- **个人 TODO**：按个人标识筛选待办，把同一任务涉及的位置集中显示。
- **资源管理**：提醒工作区外文件，屏蔽暂时不需要显示或搜索的资源。
- **集中配置**：调整功能和图标风格，统一保存个人偏好与项目集合。

## 安装与开始使用

需要 VS Code 1.88.0 或更新版本。扩展 ID 为 `scnabla.catlas-hub`。

从[版本下载](https://github.com/scnabla/CAtlas-Hub/releases)获取 `.vsix` 安装包，在 VS Code 扩展视图右上角菜单中选择“从 VSIX 安装”，选中安装包并按提示完成安装。

1. 打开活动栏中的“CAtlas Hub”，选择“添加项目并创建集合”，加入文件夹或 `.code-workspace` 并设置别名。
2. 点击集合中的项目，选择在当前窗口或新窗口打开。
3. 打开源码，在“增强函数大纲”中查看和定位符号，在资源管理器中查看“已打开文件目录”。
4. 在“配置 → 代码 TODO”中设置个人标识，通过编辑器右键“快速标记”添加待办，再展开资源管理器中的“代码 TODO”查看。

使用旧扩展 ID 的用户需安装新版并停用旧扩展；当前版本不自动导入旧扩展数据。

## 项目集合

项目集合标题栏提供添加项目、选择集合、修改数据保存位置、刷新和退出操作。已有项目可以通过右键修改别名、说明、标签和路径，也可以移出集合。

每个窗口选择一个集合。退出集合会保留集合内容、项目文件和已打开的窗口，之后可通过“选择项目集合”重新选择。

## 已打开文件与外部文件提醒

资源管理器中的“已打开文件目录”按目录展示当前窗口打开的普通文件。连续的单层目录会合并显示，点击文件即可回到对应标签。目录默认展开，需要折叠时使用右键“折叠此目录”或标题栏的折叠操作。

在“配置 → 项目与资源操作 → 已打开文件视图”中，可以选择“目录树”或“VS Code 原生”。隐藏原生视图时，如出现手动操作提示，按提示完成即可。

启用“非项目标签自动移至末尾”后，工作区外文件等非项目标签会放到后方，项目内标签保持原有顺序。关闭自动整理后，仍可执行“将非项目标签移到末尾”。

工作区外的普通文件可显示前景色、`‼` 徽标、路径提示和状态栏提醒。点击状态栏提醒可以查看并切换外部文件。提示样式可在“配置 → 工作区外文件提醒”中调整，实际显示效果受当前主题和 VS Code 装饰设置影响。

## 增强函数大纲

在 CAtlas Hub 侧栏展开“增强函数大纲”，即可查看当前源码文件的函数、方法、类型等符号。单击条目跳转到源码，光标移动时当前函数同步高亮。

- 选择“仅函数”“函数与类型”或“全部符号”，并按阅读习惯排序。
- 搜索当前文件中的符号；C/C++ 条件编译可按 `#elif` 等指令或条件表达式筛选。
- 在“配置 → 当前生效功能”中选择仅原生大纲、仅增强大纲或同时使用。选择仅增强时，按视图提示隐藏原生大纲。
- 在“配置 → 函数大纲显示”中调整缩放、行号和标记，外观可选择跟随 VS Code、Source Insight 浅色或黑色。

大纲需要对应语言扩展提供符号。C/C++ 等工程应先安装并配置相应语言扩展。

## 个人 TODO

“代码 TODO”默认只显示个人标记，并按任务描述归类。设置个人标识后，快速标记会生成类似下面的注释：

```c
// TODO(dev): 添加串口超时处理
// FIXME(dev): 修复异常返回路径
```

`dev` 是示例标识，可替换为自己的简短标识。

- 在当前文件或整个工作区中查看待办，按任务描述或标签分组，并按文字、文件名和路径筛选。
- 使用右键菜单快速标记、重复上次标记、修改类型、完成或删除标记；添加时可以选择已有任务描述。
- 默认支持 `TODO`、`FIXME`、`BUG`、`HACK`、`XXX`，可在配置中启用其他关键词、自定义关键词和 Markdown 未完成项。
- 需要查看工程已有标记时，开启“配置 → 代码 TODO → 显示项目已有标记”。大型工程中的结果数量和扫描耗时会随之增加。
- 如需快捷键，使用“配置 → 代码 TODO → 设置快速标记快捷键”。需要重新扫描时，执行“完整更新代码 TODO（重新读取）”。

TODO 只识别受支持语言的注释，`#ifdef DEBUG` 等代码不会作为待办。超过 2 MiB 的文件会跳过；个人标记与项目已有标记各最多保留 5,000 条结果。

标记保存在源码注释中，会随源码提交。删除标记会保留注释正文。

## 屏蔽与恢复资源

在资源管理器中选中文件或目录，右键选择“CAtlas Hub: 屏蔽所选资源（目录、搜索与监控）”，即可将其从目录展示、搜索和文件监控中排除。屏蔽不会删除实际文件。

需要恢复时，执行“CAtlas Hub: 管理/取消屏蔽”。需要屏蔽同一扩展名的文件时，选择“CAtlas Hub: 屏蔽同类型文件（按扩展名）”。

## 配置与图标

侧栏“配置”视图集中提供项目打开方式、标签整理、函数大纲、TODO、工作区外文件提醒和 VS Code 内置 AI 开关。修改选项后自动保存并应用。

集合内项目可以使用集合功能配置，也可以选择“跟随个人默认”；集合外项目使用个人默认值。工作区显式设置优先，配置项的悬浮提示可查看实际来源。

独立的“打开 VS Code 配置文件”入口可直接打开用户 `settings.json`，手工编辑后需要保存。

“配置 → 项目与资源操作 → 图标风格”提供两种选择：

- **简约彩色**：使用自绘图形和分类配色，函数为 `f`、变量为紫色 `var`、宏定义为 `#`。
- **VS Code 原生**：树视图使用原生图标，增强大纲使用单色符号。

图标切换立即生效。高对比度主题下自动使用原生或单色图标；已安装的文件图标主题保持不变。

## 数据保存位置

个人偏好、项目集合和别名统一保存在插件数据文件中，由插件自动读写，无需手工编辑。默认位置为：

| 系统 | 默认位置 |
| --- | --- |
| Windows | `%APPDATA%\CAtlas Hub\personal-data.dat` |
| Linux | `$XDG_CONFIG_HOME/CAtlas Hub/personal-data.dat`；未设置绝对路径时使用 `~/.config/CAtlas Hub/personal-data.dat` |

点击项目集合标题栏的“修改项目集合数据保存位置”选择新目录，会整体移动个人偏好和集合数据。多个窗口及重启后继续使用新位置。

如果目标目录已有插件数据，可以确认使用该目录数据或取消。确认后偏好和集合一起切换，原位置的数据保留，不合并或覆盖。移动数据不会复制项目源码；项目位置变化后，可右键重新选择项目路径。

插件数据和本机 TODO 缓存包含项目路径或标记描述，共享前请检查其中的个人信息。
